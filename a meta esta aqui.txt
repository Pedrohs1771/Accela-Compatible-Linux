## 1. Lista de Funcionalidades Recomendadas
 * **AOB Pattern Scanning (Linux ELF):** Varredura dinâmica de assinaturas de bytes na memória do processo da Steam (steam) para localizar funções de licença, garantindo que o utilitário não quebre após atualizações da plataforma.
 * **Auto-Fetch de Manifests (SteamDB API integration):** Script em segundo plano para baixar tabelas de AppIDs e DLCs automaticamente, sem necessidade de configuração manual.
 * **Hot Reloading:** Atualização dinâmica de licenças locais via sinais de sistema (SIGUSR1 ou inotify), aplicando novos conteúdos sem reiniciar o cliente.
 * **Filtro de Injeção Condicional (Anti-VAC Dinâmico):** Desativação automática de ganchos de memória sempre que um processo de jogo com proteção VAC ou EAC for detectado pelo monitor de processos do sistema (procfs).
## 2. Como Integrar Interface Nativa (Método Millennium no Linux)
O framework Millennium permite injetar código frontend (CSS/JS) diretamente no cliente WebKit/Chromium da Steam. No Linux, a integração é feita forçando o cliente a carregar a biblioteca de interface customizada.
### Passos para Configuração:
 1. **Download do Módulo:** Baixe a build correspondente para Linux do Millennium (libmillennium.so).
 2. **Diretório de Instalação:** Mova o arquivo .so para o diretório de execução da Steam (geralmente em ~/.local/share/Steam/ ou no diretório raiz do pacote Flatpak, dependendo da instalação).
 3. **Parâmetro de Inicialização (LD_PRELOAD):** Modifique o atalho de inicialização da Steam ou adicione ao script de boot a variável de ambiente que força o carregamento da biblioteca antes do processo principal do Chromium iniciar:
   ```bash
   LD_PRELOAD="/caminho/para/libmillennium.so" steam
   
   ```
 4. **Desenvolvimento do Tema/Aba:** Dentro da pasta de temas do Millennium (~/.local/share/Steam/plugins/), crie um script frontend que renderize uma nova aba no menu de configurações da Steam para gerenciar seus manifests e IDs de DLCs locais de forma visual.
## 3. Emulação de DLCs e Licenças no Linux (Proton/Wine)
Para jogos executados via camada de compatibilidade Proton, o método mais estável e que mitiga conflitos com anti-cheats locais consiste na substituição da biblioteca interna do jogo ou uso de ferramentas baseadas em Rust (como alternativas ao *CreamAPI* portadas para Linux, ex: *ScreamAPI* ou *SmokeAPI*).
### Passos para Configuração:
 1. **Identificação da Arquitetura:** Localize a DLL original do jogo (steam_api.dll ou steam_api64.dll) na pasta do executável.
 2. **Substituição por Wrapper Open-Source:** Substitua a DLL original pelo binário emulador open-source compilado e renomeie a original para steam_api_o.dll (para que o emulador possa repassar chamadas legítimas).
 3. **Configuração de AppIDs:** Crie um arquivo de texto de configuração (como cream_api.ini ou correspondente do utilitário escolhido) no mesmo diretório, listando as DLCs que devem retornar true na checagem local.
 4. **Override no Proton:** Para garantir que o Proton carregue a DLL modificada em vez da biblioteca padrão do Wine, configure as opções de inicialização do jogo diretamente na Steam com o seguinte comando:
   ```bash
   WINEDLLOVERRIDES="steam_api,steam_api64=n,b" %command%
   
   ```
*Nota de Segurança:* Jogos com verificação estrita em servidores de terceiros ou com sistemas anti-cheat a nível de kernel/processo ativo monitoram modificações nessas bibliotecas e podem aplicar restrições se detectarem hooks na memória.

```javascript
(function () {
  const BRIDGE = "http://127.0.0.1:32175";
  const ROOT_ID = "lumatools-manager-panel";

  async function injectLumaTab() {
    // Procura o contêiner de configurações na UI nativa da Steam (CEF)
    const steamSettingsMenu = document.querySelector(".SettingsDialogHeader");
    if (!steamSettingsMenu || document.getElementById(ROOT_ID)) return;

    const lumaTab = document.createElement("div");
    lumaTab.id = ROOT_ID;
    lumaTab.className = "SettingsDialogButton";
    lumaTab.innerText = "Luma-Tools Manager";

      // Abre a interface de gerenciamento de DLCs locais e Manifests
      const appID = prompt("Digite o AppID do jogo para injetar as DLCs locais:");
      if(appID) {
         await fetch(`${BRIDGE}/inject-dlc`, {
             method: "POST",
             headers: { "Content-Type": "application/json" },
             body: JSON.stringify({ appid: appID })
         });
      }
    });
    steamSettingsMenu.appendChild(lumaTab);
  }

  window.setInterval(injectLumaTab, 2000);
})();

```
