# Windows Known Limitations

- Windows ARM is not supported initially.
- The Windows artifact is RC until tested manually on Windows 10/11 hardware.
- SteamCMD may require account login for private or license-gated Workshop
  items.
- Metadata-only DLC is detected but not installed.
- Multiplayer/online behavior needs a second real player for final validation.
- Antivirus or SmartScreen may warn on new unsigned PyInstaller binaries.
