# LumaTools Companion for Millennium

This is a visual companion for the Steam UI. It talks only to the local
LumaTools bridge at `http://127.0.0.1:32175`.

Supported actions:

- Show LumaTools status.
- Show queue count and detected Steam libraries.
- Bring the running LumaTools window to the foreground.

Not supported by design:

- License or DLC entitlement changes.
- GreenLuma or DLL injection.
- Steam cache mutation.
- Starting downloads from Steam for content the user is not entitled to.

To test, copy this folder to your Millennium plugins directory and keep
LumaTools open.
